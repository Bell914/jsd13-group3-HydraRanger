# Personalized Size Recommendation

## Product goal

ช่วยให้ลูกค้าเลือกไซส์ได้มั่นใจขึ้น ลดความลังเลก่อนเพิ่มสินค้าในตะกร้า และสร้างประสบการณ์ที่เหมาะกับแต่ละคน

## User problem

ลูกค้าออนไลน์ไม่สามารถลองสินค้าได้ ตารางไซส์อาจอ่านยาก และความชอบเรื่องความพอดีของแต่ละคนไม่เหมือนกัน

## MVP flow

1. ลูกค้า Login และเปิด Profile > Size & Fit
2. เลือกหน่วยนิ้วหรือเซนติเมตร แล้วกรอกรอบอก รอบเอว รอบสะโพก และทรงที่ชอบ
3. ยืนยัน Consent แล้วบันทึกข้อมูล
4. เปิด Product Detail เพื่อดูไซส์แนะนำ เหตุผล และระดับความมั่นใจ
5. กดเลือกไซส์ที่แนะนำ หรือเลือกไซส์อื่นเอง
6. ลูกค้าแก้ไขหรือลบข้อมูลสัดส่วนได้ทุกเมื่อ

## Recommendation rules

- หาก Product มี `size_chart` ระบบเลือกไซส์จากรอบอกของเสื้อและความหลวมที่ลูกค้าชอบ
- หากไม่มี `size_chart` สินค้ากลุ่มเสื้อใช้รอบอกและรอบเอว ส่วนกางเกงใช้รอบเอวและรอบสะโพกเทียบกับเกณฑ์ S/M/L
- ตารางไซส์หน้า Product และกฎแนะนำไซส์ใช้ข้อมูล `BODY_SIZE_GUIDE` ชุดเดียวกัน
- ระบบแสดงผลได้ทั้งนิ้วและเซนติเมตร แต่บันทึกค่ามาตรฐานเป็นเซนติเมตร
- ทรง `relaxed` ขยับคำแนะนำขึ้นหนึ่งไซส์เมื่อมีไซส์นั้นขาย
- ระบบแนะนำเฉพาะไซส์ที่ Product มีให้เลือก
- คำแนะนำเป็นตัวช่วย ไม่ใช่การรับประกันความพอดี

## Prototype assumption

สินค้าของโปรเจกต์เป็นข้อมูลสมมติ จึงกำหนดช่วงสัดส่วน S/M/L สำหรับต้นแบบ OCCASION ขึ้นมาเอง โดยระบุชัดเจนว่าเป็น “สัดส่วนร่างกาย” ไม่ใช่ขนาดของตัวเสื้อผ้า หากทีมปรับมาตรฐานภายหลัง ให้แก้ข้อมูลกลางเพียงไฟล์เดียว

## Privacy decisions

- บันทึกข้อมูลเมื่อ Customer ให้ Consent เท่านั้น
- API ทุกตัวต้องใช้ Customer JWT
- Customer อ่านและแก้ไขได้เฉพาะข้อมูลของตนเอง
- Admin Customer API ไม่ส่งข้อมูลสัดส่วนรายบุคคล
- มีปุ่มลบข้อมูลทั้งหมด
- Dashboard ในอนาคตควรใช้เฉพาะข้อมูลสรุปที่ไม่ระบุตัวตน

## Acceptance criteria

- Customer ที่ยังไม่ Login เห็นคำเชิญให้ Login
- Customer ที่ยังไม่มีข้อมูลเห็นทางลัดไปหน้า Size & Fit
- ข้อมูลนอกช่วงที่กำหนดถูก Validation ปฏิเสธ
- ไม่สามารถบันทึกข้อมูลโดยไม่ยืนยัน Consent
- Product ที่มี Size Chart แสดงความมั่นใจสูง
- Product ที่ไม่มี Size Chart แสดงความมั่นใจปานกลาง
- กดปุ่มแนะนำแล้วไซส์นั้นถูกเลือกใน Product Detail
- ลบข้อมูลแล้วหน้าสินค้าไม่แสดงคำแนะนำเดิม

## Success metrics for a future release

- เปอร์เซ็นต์ลูกค้าที่ตั้งค่า Size & Fit สำเร็จ
- เปอร์เซ็นต์ผู้ใช้คำแนะนำแล้วกด Add to Cart
- Conversion rate ก่อนและหลังเปิด Feature
- อัตราการเปลี่ยนหรือคืนสินค้าเพราะไซส์
- Feedback ว่าคำแนะนำพอดี เล็ก หรือใหญ่

## Next iteration

- เก็บ Feedback หลังได้รับสินค้าโดยไม่เก็บข้อมูลเกินความจำเป็น
- เพิ่ม Size Chart แยกตาม Product และ Category
- แสดง Analytics แบบไม่ระบุตัวตนให้ Product Owner
- ทดลอง A/B Test เปรียบเทียบ Product Detail แบบเดิมกับแบบมีคำแนะนำไซส์
